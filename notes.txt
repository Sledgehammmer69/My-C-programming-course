Next we gonna use functions....a simple function

in this case we're gonna create our function above main
the void means the function has no return value and the void in meow(void) means the funnction doesnt take any value in


void meow(void)
{
    printf("meow\n");
}

int main(void)
{   
    for (int i = 0; i < 3; i++)
    {
        meow();
    }
}

ultimately we want our main to be above eerything else to ensure that the first thing we see when we open the editor 
is the main function but C follows a strict rule whereby it reads from top to bottom....so we can use prototype:

//this is a prototype
void meow(void);

int main(void)
{   
    for (int i = 0; i < 3; i++)
    {
        meow();
    }
}

void meow(void)
{
    printf("meow\n");
}
